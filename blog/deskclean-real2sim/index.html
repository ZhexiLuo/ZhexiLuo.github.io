02 / FOLLOW THE CHAIN复现是怎样发生的

让每一步，都有来处。

几何决定接触，接触推动物体。
渲染跟随保存的物理轨迹。

  1. 01

    看清动作

    OBSERVE

    从 6 秒原片拆出簸箕定位、刷子推进与撤刷；保留遮挡和尺度的不确定性。

    RGB → 任务与尺寸假设
  2. 02

    建立场景

    RECONSTRUCT

    工具共享米制、Z-up 坐标。簸箕保留可进入的开口，刷毛分别表达碰撞与外观。

    场景描述 → MJCF / 视觉资产
  3. 03

    交给物理

    EXECUTE

    根据视频编写技能与 IK 控制器，驱动 TIAGo++ 双臂。6 枚自由刚体方块由实际接触推进。

    ctrl + mj_step → 状态 / 接触
  4. 04

    换个角度

    RENDER

    用官方 USDExporter 导出轨迹，在 Blender 中补齐视觉工具、灯光和三个相机。

    USD → global / ego / gripper
